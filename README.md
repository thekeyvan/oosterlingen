# Oosterlingen — interior plans

Static site served at **https://oosterlingen.keyvanmahmoudi.com** (GitHub Pages).

| Path | What |
|---|---|
| `index.html` | Landing page with links and downloads |
| `bathroom/` | Interactive 3D bathroom model (self-contained, three.js bundled in) |
| `downloads/` | Files to download: offline model, PDFs |

The bathroom model keeps the current selection in the page link (`#cfg-…`). To share an exact
configuration, copy the address bar after choosing the options.

All sizes in mm, taken from the developer's drawings; verify on site before ordering or building.
